# 单词记忆微信小程序

首页提供**新单词**、**复习**入口与**拍照收词**卡片。按间隔重复算法（类似 Leitner/Anki 思路）安排复习。
支持**多账号**：不同账号绑定不同词库，学习进度与记录完全独立。

## 一、如何运行

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → 导入项目 → 选择本文件夹（`vocab-review-miniprogram`）
3. AppID 已配置为已注册的小程序「启航成长记」（`wx883c54d2308a2450`），导入时直接沿用即可，编译就能在模拟器中运行
4. 点「编译」即可在模拟器查看效果（本项目无第三方依赖，无需构建 npm）
5. 给家人长期使用：走**体验版**流程，操作见「二、编译与发布体验版」
6. 正式发布（可选）：个人主体无需微信认证即可提交审核、发布上线，之后可在微信中搜索使用（本项目 ICP 备案已通过）

## 二、编译与发布体验版（给家人长期使用）

**个人未认证账号同样适用**：体验版不需要认证、不需要提交审核，上传后家人扫码即可长期使用，不依赖开发者工具。

### 1. 编译预览（每次改代码后）

1. 微信开发者工具打开本文件夹
2. 点工具栏「**编译**」，模拟器即可查看最新效果
3. 本项目纯前端、无第三方依赖，**无需**执行 `npm install` 或「工具 → 构建 npm」；若模拟器白屏，用「工具栏 → 清缓存 → 清除全部缓存」后再编译

### 2. 上传（生成开发版本）

1. 点工具栏「**上传**」
2. 填版本号（如 `1.0.0`）和备注（如"初版"），点「上传」
3. 前提：开发者工具里登录的微信必须是该 AppID 的**管理员**，或后台「成员管理」中已添加的**项目成员**

### 3. 选为体验版

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) →「管理」→「版本管理」→「**开发版本**」列表找到刚上传的版本 → 点右侧「**选为体验版**」（新版后台该按钮可能收在「···」等次级菜单里，行上主按钮「提交审核」是正式版发布用，**不要点**）

> **发布核对（防"体验用户看不到新版"，踩坑 #15）**：上传后确认左侧「**体验版**」栏的版本号/时间已变成本次上传，才算切换成功；体验用户若仍见旧版，删除小程序后重扫体验版二维码即可。

### 4. 添加体验成员

「**管理 → 成员管理 → 体验成员**」→ 添加家人的微信（个人主体上限 **15 人**）

### 5. 家人扫码使用

「版本管理 → **体验版**」处有体验版二维码，家人用**微信「扫一扫」**进入（须使用被添加的微信号）。之后每次打开都会使用最新体验版，无需开发者工具、无需在线。

### 6. 更新版本（迭代发布）

改完代码后，重复「**2. 上传 → 3. 选为体验版**」两步即可；家人下次进入小程序会自动更新到新版本（版本号递增便于区分）。

> **实现时间戳（宪法见 AGENTS.md 强制规则 8）**：`app.js` 底部维护「最后实现」时间戳，由 AI 编码代理在每轮代码实现完成后自动更新为本机当前时间（年月日+时分秒），仅作代码内的最后实现标记，与上传版本号无关。小程序界面不显示任何版本内容；核对体验版新鲜度以 mp 后台「版本管理」的提交时间为准。

> **真机朗读提示**：体验版要能发声，需先在后台「开发 → 开发管理 → 开发设置 → 服务器域名」的「downloadFile 合法域名」加入 `https://dict.youdao.com`（详见「功能说明 → 学习模式 → 关于朗读」）。配置细节与踩坑记录见 `docs/运维手册/01-微信平台配置与踩坑手册.md`。

### 临时调试

不想走体验版流程时，工具栏「**预览**」可生成约 2 小时有效的临时二维码，适合自己随时内测。

## 三、功能说明

### 账号（多词库）
- 首页顶部为**当前账号卡片**，点击即可**切换账号**
- 目前内置两个静态词库账号，各自绑定独立词库：
  - **初中人教版**：人教版七~九年级单词及短语 + 初中高频考点单词短语（`data/junior.js`，343 条）
  - **小学人教版**：人教版三~六年级单词及短语 + 小学高频考点单词短语（`data/primary.js`，229 条）
- **拍照生词并入当前账号（R14，2026-10-02）**：拍照收录的词进入**当前账号**的「拍照生词队列」（本地存储 `vocab_photo_words_<账号>`），点「新单词」时**优先于教材词出批**（拍了就学，每批仍 35 词），队列学完自动回到教材顺序。原「拍照生词本」独立账号已退役，旧数据自动迁入初中账号
- 切换账号后，**词库、学习进度、复习任务、学习记录、拍照生词队列同步切换**，互不干扰
- 账号定义在 `data/accounts.js`，可自行增删账号或改绑词库
- **词库页**（R09，2026-10-01；R09-2 全账号可删，2026-10-02）：点击首页底部统计区**「词库总量」**进入当前账号的词库页，支持按**单词或释义搜索**、点单词中英连读、查看每个词的状态（待学习 / 第N批·复习中 / 已完成）——可用来查某个词学没学、在第几批。**所有账号均可删除**：行右侧「删除」单删、右上「管理」勾选**批量删除**（「全选结果」作用于当前搜索结果）；**删除已进入学习的词会同时把它移出复习批次与错词本**（历史学习记录保留，统计随之更新），待学词删除后不再进入学习。教材词库删除为**软删除**（记录在本地存储，`data/*.js` 源文件不动，不可恢复）；从词库页删掉的内置词，拍照收词时可重新收录（不再标「已收录」）

### 拍照收词
- 首页蓝色「📷 拍照收词」卡片进入：**拍照 / 相册选图 → 自动识别印刷体英文单词 → 勾选 → 批量查询释义 → 收录**
- 识别双路线（R05-A，2026-10-01）：**主路线 = 智谱 GLM 视觉识别**（图片压缩后上传智谱云识别，准确率高、能还原 dialog(ue)→dialogue 这类拼写注记）；**断网或失败自动降级本机 VisionKit 识别**（图片不出设备）。已收录的词连同释义 / 音标存本地快照，之后不依赖网络
- 识别透明与纠错（R06，2026-10-01）：做过注记还原或低置信的词在候选页词下方灰色小字标注原图写法；**长按候选单词**或对待补义词点「**AI 纠错**」可带原图核对拼写，建议经确认后替换；`AUTO_FIX` 开关（默认关）开启后查义失败词自动拉取 AI 建议（仅展示，点「改用它」生效）
- 查义为有道词典接口（免插件、免认证），释义做 **K12 精简**（R07-A，2026-10-01）：每词性只保留首个常用义、最多 2 个词性、30 字内，滤除人名/语域标注等百科噪声（实测 176 字 → 29 字）；与**当前账号**有效词库（教材词 + 本账号拍照词）重复的词**标灰显示「已收录」且不可勾选**（另一教材的词允许收录）；已在当前账号拍照队列中的词自动滤掉不显示
- 识别候选列表每行右侧红色「**修改**」点按可修改单词拼写（预填当前词，仅限英文单词/短语），确认后更新候选并重算「已收录」状态（R08，2026-10-02 入口前移至识别列表）；**不支持手动修改中文释义**——释义只随英文单词联动更新，由「查询释义」统一获取。查义失败的词标「待补义」，可**重试**或**AI 纠错**；待补义词补齐释义前不进入收录
- 收录后词已进入当前账号队列，完成页一键「去学习」回到新单词页即**优先出批**，按每批 35 词进入 10 次间隔复习
- **启用 AI 主路线（一次性）**：
  1. 注册 [智谱开放平台](https://open.bigmodel.cn) → 控制台创建 **API Key**（建议低额度，便于泄露时撤换）
  2. 复制 `utils/llm.config.example.js` 为 `utils/llm.config.js`（同目录），填入 `apiKey`（模型名 / 接口域名同文件可调，以智谱文档为准）。**该文件已被 `.gitignore` 排除、不会提交到仓库——本仓库为公开仓库，Key 严禁直接写进任何代码文件**。不创建该文件则始终走本机 VisionKit 识别，功能不受影响
  3. 代价说明（ADR-002 修订红线②的唯一豁免）：Key 随小程序包分发、可被反编译提取；照片会上传智谱云端识别
- **真机使用前的一次性配置**（开发者工具模拟器不受限）：
  1. mp 后台「用户隐私保护指引」声明「**摄像头**」与「**选中的照片或视频信息**」两项（2023-09 起强制，不配置真机拍照会被拦截），并在指引中补充照片用于 AI 识别、上传第三方的说明。新版后台入口：左下角账号头像 →「账号设置」→「服务内容声明」→「用户隐私保护指引」（旧版为「设置 → 服务内容声明」）；提交后需审核通过生效
  2. 「**request 合法域名**」加入 `https://dict.youdao.com`（downloadFile 已有，request 是独立列表需分别配置）；启用 AI 主路线时再加入 `https://open.bigmodel.cn`
  3. 微信基础库 ≥ 2.27.0（降级路线 VK 要求）；机型不支持时页面会提示
  4. 详细操作步骤与踩坑记录：`docs/运维手册/01-微信平台配置与踩坑手册.md`
- 手写体识别效果差，适合印刷体；光照充足、镜头稳定效果更好

### 新单词
- 每次出一批 **35 个**新单词，**按当前账号词库顺序**依次取词
- 列表上方有**播报模式切换**，默认「**手动点读**」：
  - **手动点读**：点任意单词的整行（英文 / 中文 / 空白处），只报读该词（先英文、再中文，释义自动分段），连读 3 遍、读完即停
  - **自动顺读**：点任意行后，本行连读 3 遍，播完自动接续之后的每个单词（同样英文 + 中文连读 3 遍），逐词向后直到最后一个词或点「停止学习」，当前词高亮并自动滚动到可视区域；右上角「开始学习」从第 1 个词起自动逐词连播，再点变「停止学习」随时暂停（已播完部分不记录进度，可随时从任意一行重新开始）
- 点击"完成学习，记入记录"后，记录本批的**学习日期 + 全部单词内容**，随后自动进入**学习模式**（见下）
- 词库用完会提示（可切换其他账号继续学）

### 学习模式（每批确认后）
每批单词**确认记入记录后**，可选择两种学习方式（学习记录页也可随时重学任意批次）：

| 方式 | 显示内容 | 点击后 |
|---|---|---|
| **展示英文** | 英文单词 | 翻出中文释义，并**报读英文 + 中文**（连读为 1 遍，间隔约 1.2 秒，共 3 遍） |
| **展示中文** | 中文释义 | 翻出英文单词，并**报读英文 + 中文**（同上节奏） |

- 两种模式点击后都统一报读"英文单词 + 中文释义（取首个义项，短词更易命中发音接口）"，**连读为 1 遍、每遍间隔约 1.2 秒、连续 3 遍**，方便专注跟读；再点一次会从头重报
- 支持"全部显示"和"重新开始"，并显示已点击进度（X/35）
- **每行右侧操作区**：🔊 快读一遍（英文 + 中文）；「**拓展**」弹出半屏面板，分栏展示该词的**衍生词（同根词）、近义词、3 条双语例句**（例句中目标词加粗，点右侧 🔊 逐句朗读）。数据来自有道词典接口：首次点击在线查询，之后**本地缓存**（离线也能看）；简单词可能没有衍生词段，面板自动隐藏，属正常现象

**关于朗读**：使用「有道词典」公开发音接口实现语音合成，**无需 API Key、无需插件、不受个人主体未认证限制**：
- 英文单词/短语：有道词典发音（`type=2` 美音，偏好英式可改 `utils/tts.js` 顶部 `EN_VOICE_TYPE = 1`），单词与常见短语发音稳定
- 中文含义：有道词典词条发音（`https://dict.youdao.com/speech?le=zh&audio=…`），自动清理词性标注（n. / v. / int. 等）、剥离括号注释（复数、拼写提示），并**按「，；空格、。」等分隔符把释义拆成多段逐段连播**（多个义项、含用空格连接的都能各读出来）；仅对词典收录的词语有效，个别生僻词无声但不报错、不影响其他功能

真机使用前的唯一准备：配置**合法域名**（开发者工具模拟器不受限，可直接发声）：

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) →「开发」→「开发管理」→「开发设置」→「服务器域名」
2. 在「**downloadFile 合法域名**」中加入 `https://dict.youdao.com`
3. 重新编译后真机即可朗读英文并播放中文释义

### 复习
每一批新单词共安排 **10 次复习**，节点为学习日之后的：

> 第 1、2、3、4、6、8、11、13、16、21 天

- **前 3 次**（第 1、2、3 天）：复习该批**全部** 35 个单词，标记"忘记"的词进入该批的**遗忘池**
- **后 7 次**（第 4、6、8、11、13、16、21 天）：只复习**前几天复习中答错/忘记的单词**（遗忘池）；某轮答对则移出遗忘池，再错则保留到后续轮次
- 遗忘池为空时，该轮自动完成（说明这批掌握得好）
- **同一天多个批次到期时自动合并**为一次复习，重复单词去重
- 错过某天也没关系，逾期的任务会在下次打开时**补做**
- 复习交互：显示单词 → 点击"显示释义" → 自评"记得 / 忘记了" → 结束后显示统计并记录
- **拓展入口**：显示释义后卡片下方可点「🌱 拓展」查看该词衍生词 / 近义词 / 例句（与学习模式同款弹层，首次在线查询后本地缓存）
- **错词本联动**：判"忘记了"的词自动进入错词本；判"记得"且该词在错词本中会自动移出，并提示"已移出错词本"
- **没有到期任务的「今日看板」**：今天无到期批次时，复习页展示任务看板——连续学习天数、上次复习复盘（日期/批次/词数/错词数）、错词本待巩固词数、下一次到期批次与倒计时，让家人清楚"没有落后"
- **没有任务也能练**：看板提供两个动作——「复习错词本 N 词」（自由复习：答对自动移出错词本、忘记保留，**不计入**正式复习次数）与「提前复习第 N 批」（对未来即将到期的最近批次提前做一轮，完成后**计入**该批正式复习进度）

### 错词本
- 首页有一张红色系**错词本**卡片，实时显示错词数量，点击进入
- 错词本 = 各批次**遗忘池的全局聚合**（同一词跨批次自动合并去重），展示单词、释义与来源批次
- 三种"移出错词本"途径：
  1. 复习时判"记得"（自动移出）
  2. 错词本列表点「我会了 ✓」（手动移出）
  3. 第 4~10 轮遗忘词复习中答对（自动移出）
- 点错词可**快速朗读**（英文 + 中文连读一遍，回顾发音）

### 教程总览
- 首页新增**教程进度卡片**：进度条 + 每批一个圆点（🟢 绿点=该批 10 次复习已完成、橙色描边=正在复习、绿框=当前待学批、灰点=未学），一眼看到整本教程走到哪
- 点击进入**教程总览**页：把当前词库按每批 `BATCH_SIZE`（35 词）自动**划分成若干「章」**，逐章显示【状态徽标】复习进度 X/10、遗忘词数（联动错词本）
- 点任意一章可**展开看该批全部单词（含释义）与每次复习记录**；未学/当前批点「去学习」直接进入新单词页，已学批点「重学」直接进入学习模式
- **可直接复习任意已学批**：正处在复习过程中的批次（复习中状态）右侧有「复习 ▸」，点它会直接进入该批本轮复习（前 3 轮复习全批单词、第 4 轮起复习遗忘池），完成计入该批复习次数并联动错词本；未轮到的新批会提示按顺序学习
- 切换账号后总览随账号同步切换（词库、进度各自独立）

### 学习记录
首页底部"查看学习记录"可翻看：每批的学习日期、全部单词内容、10 次复习的完成情况、每次复习的对错统计、当前遗忘池剩余词数。每批带有"两种方式学习"按钮，可随时进入学习模式重学。

## 四、替换或扩充词库

编辑 `data/junior.js` / `data/primary.js`，保持格式即可（`w`=单词或短语，`m`=释义；`p`=音标为可选项，现有词库未包含音标）：

```js
module.exports = [
  { w: 'abandon', m: 'v. 放弃；抛弃' },
  { w: 'be good at', m: '擅长……' },
  ...
];
```

已学过的记录保存了单词快照，替换词库不影响历史记录；新批次从上次的进度位置继续按顺序取词。

新增账号或改绑词库：编辑 `data/accounts.js`：

```js
module.exports = {
  list: [
    { id: 'junior', name: '初中人教版', desc: '初中人教版单词短语 + 高频考点', bank: require('./junior.js') },
    { id: 'primary', name: '小学人教版', desc: '小学人教版单词短语 + 高频考点', bank: require('./primary.js') }
  ]
};
```

拍照生词不占 `accounts.js`（R14）：词存各账号队列 `vocab_photo_words_<账号>`，由拍照收词自动维护，`accounts.js` 只配置初中 / 小学两个教材账号。

## 五、可调参数

在 `utils/store.js` 顶部：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `BATCH_SIZE` | 35 | 每批新单词数量 |
| `OFFSETS` | [1,2,3,4,6,8,11,13,16,21] | 10 次复习的天间隔 |
| `FULL_REVIEW_ROUNDS` | 3 | 前几次复习全部内容 |

拍照收词相关（在各自文件顶部）：

| 参数 | 位置 | 默认值 | 说明 |
|---|---|---|---|
| `CONCURRENCY` | `utils/lookup.js` | 4 | 批量查词并发路数 |
| `MAX_POS` | `utils/lookup.js` | 2 | 入库释义最多保留的词性块数（R07-A K12 精简） |
| `MAX_CHARS` | `utils/lookup.js` | 30 | 释义总字数上限（子义边界收缩，首块超限保留整块） |
| `TIMEOUT` | `utils/lookup.js` | 8000 | 单词查词超时（毫秒） |
| `MIN_LETTERS` | `utils/wordParser.js` | 2 | 候选词最少字母数（短于此过滤） |
| `MAX_LETTERS` | `utils/wordParser.js` | 16 | 候选词最多字母数；超过的 OCR 粘连串先走还原（标记切块 + 词典切分），仍超长按噪声丢弃 |
| `MIN_SEG_WORD` | `utils/wordParser.js` | 3 | 粘连串词典切分的最小命中词长（防 an/as 等超短词把真词误切） |
| `COVER_RATIO` | `utils/wordParser.js` | 1/3 | 无标记超长串的词典覆盖率下限，低于按噪声整串丢弃 |
| `API_KEY` | `utils/llm.js` | （空） | 智谱开放平台 Key；为空 = 不启用 AI 主路线，全程本机识别 |
| `MODEL` | `utils/llm.js` | glm-4v-flash | 智谱视觉模型名，按控制台可用列表可换 |
| `TIMEOUT` | `utils/llm.js` | 20000 | AI 识别总时限（毫秒），超时自动降级本机识别 |
| `MAX_SEND_EDGE` | `utils/llm.js` | 1600 | 发送 AI 前压缩到的图片长边上限（px） |
| `AUTO_FIX` | `utils/llm.js` | false | R06-B 开关：查义失败词自动拉取 AI 纠错建议（仅展示，点「改用它」生效） |
| `MAX_EDGE` | `utils/ocr.js` | 1280 | 单块长边上限（px），超宽/超高图按版面分块 |
| `MIN_SHORT_EDGE` | `utils/ocr.js` | 640 | 压缩小图（长边 ≤1280）识别前的放大目标短边（px） |
| `MAX_UPSCALE` | `utils/ocr.js` | 3 | 小图放大倍数上限（963×246 词表图放大 2.6 倍后按列分 5 块识别） |

├── docs/                           开发文档：产品方案 / 技术选型 / ADR / 开发过程 / 运维手册（地图见 docs/README.md）
