# 单词记忆微信小程序

首页以**「今日学习」一键流程**为核心（R24，2026-11-23）：先复习到期批次、复习完自动衔接学新批；配套**学习进度页**查看并行批次与十轮时间线。按间隔重复算法（类似 Leitner/Anki 思路）安排复习。
支持**多账号**：不同账号绑定不同词库，学习进度与记录完全独立。

## 一、如何运行

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → 导入项目 → 选择本文件夹（`vocab-review-miniprogram`）
3. AppID 已配置为已注册的小程序「启航成长记」（`wx883c54d2308a2450`），导入时直接沿用即可，编译就能在模拟器中运行
4. 点「编译」即可在模拟器查看效果（本项目无第三方依赖，无需构建 npm）
5. 给家人长期使用：走**体验版**流程，操作见「二、编译与发布体验版」
6. 正式发布（可选）：个人主体无需微信认证即可提交审核、发布上线，之后可在微信中搜索使用（本项目 ICP 备案已通过）

## 二、编译与发布体验版（给家人长期使用）

**个人未认证账号同样适用**：体验版不需要认证、不需要提交审核，上传后家人扫码即可长期使用，不依赖开发者工具。

### 1. 编译预览（每次改代码后）

1. 微信开发者工具打开本文件夹
2. 点工具栏「**编译**」，模拟器即可查看最新效果
3. 本项目纯前端、无第三方依赖，**无需**执行 `npm install` 或「工具 → 构建 npm」；若模拟器白屏，用「工具栏 → 清缓存 → 清除全部缓存」后再编译

### 2. 上传（生成开发版本）

1. 点工具栏「**上传**」
2. 填版本号（如 `1.0.0`）和备注（如"初版"），点「上传」
3. 前提：开发者工具里登录的微信必须是该 AppID 的**管理员**，或后台「成员管理」中已添加的**项目成员**

### 3. 选为体验版

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) →「管理」→「版本管理」→「**开发版本**」列表找到刚上传的版本 → 点右侧「**选为体验版**」（新版后台该按钮可能收在「···」等次级菜单里，行上主按钮「提交审核」是正式版发布用，**不要点**）

> **发布核对（防"体验用户看不到新版"，踩坑 #15）**：上传后确认左侧「**体验版**」栏的版本号/时间已变成本次上传，才算切换成功；体验用户若仍见旧版，删除小程序后重扫体验版二维码即可。

### 4. 添加体验成员

「**管理 → 成员管理 → 体验成员**」→ 添加家人的微信（个人主体上限 **15 人**）

### 5. 家人扫码使用

「版本管理 → **体验版**」处有体验版二维码，家人用**微信「扫一扫」**进入（须使用被添加的微信号）。之后每次打开都会使用最新体验版，无需开发者工具、无需在线。

### 6. 更新版本（迭代发布）

改完代码后，重复「**2. 上传 → 3. 选为体验版**」两步即可；家人下次进入小程序会自动更新到新版本（版本号递增便于区分）。

> **实现时间戳（宪法见 AGENTS.md 强制规则 8）**：`app.js` 底部维护「最后实现」时间戳，由 AI 编码代理在每轮代码实现完成后自动更新为本机当前时间（年月日+时分秒），仅作代码内的最后实现标记，与上传版本号无关。小程序界面不显示任何版本内容；核对体验版新鲜度以 mp 后台「版本管理」的提交时间为准。

> **真机朗读提示**：体验版要能发声，需先在后台「开发 → 开发管理 → 开发设置 → 服务器域名」的「downloadFile 合法域名」加入 `https://dict.youdao.com`（详见「功能说明 → 学习模式 → 关于朗读」）。配置细节见 `docs/operations/platform.md`。

### 临时调试

不想走体验版流程时，工具栏「**预览**」可生成约 2 小时有效的临时二维码，适合自己随时内测。

## 三、功能说明

### 账号（多词库）
- 首页顶部为**头部卡**（R18，2026-10-03）：项目口号「21天记忆法 · AI 拍照收词与拓展」+ 带「**当前账号**」标签的账号名与简介（2026-11-21）+ 🔥连续学习天数；点「**使用指南**」查看按实际操作顺序编排的使用教程，点「**切换账号 ▸**」自动滚动到家庭榜
- **「今日学习」Hero 主卡（R24，2026-11-23）**：首页唯一主行动，三态自动切换——☀️ **待开始**（显示今日任务构成「复习 X 词（N 批合并）· 新学 Y 词」与预计时长，一键**先复习后学新**：复习完成页主按钮变为「继续 · 学新单词 ▸」无缝衔接；无到期任务时直接进入新单词页）；🎉 **今日已完成**（庆祝 + 「接下来：明天第 N 批第 X 轮 · M 词」预告 + 错词本自由复习入口）；🎓 **全部毕业**（词库学完且复习全部结业，引导拍照收词）。预计时长为粗估（复习词×8 秒 + 新学词×15 秒，取整到 5 分钟档）；中途退出复习不保存（全有或全无，现状规则不变）。原「新单词 / 复习」双按钮与到期引导条（R16-B）由本卡取代
- **切换账号 = 家庭榜点按**（R18）：底部家庭榜按已学词数排名（🥇🥈🥉 + 已学词数 / 连续天数），**点按某行即切换到该账号**，是首页唯一的切换入口；还没开始学的账号显示「还没开始」
- 目前内置两个静态词库账号，各自绑定独立词库：
  - **初中人教版**：人教版七~九年级单词及短语 + 初中高频考点单词短语（`data/junior.js`，343 条）
  - **小学人教版**：人教版三~六年级单词及短语 + 小学高频考点单词短语（`data/primary.js`，229 条）
- **拍照生词并入当前账号（R14，2026-10-02）**：拍照收录的词进入**当前账号**的「拍照生词队列」（本地存储 `vocab_photo_words_<账号>`），点「新单词」时**优先于教材词出批**（拍了就学），队列学完自动回到教材顺序。手动录入的词同存此队列并带「手动」来源标（2026-11-10）。原「拍照生词本」独立账号已退役，旧数据自动迁入初中账号
- **一次拍照 = 一个学习单元（R15，2026-10-03）**：每次拍照收录都会生成一个「拍照会话」（本地存储 `vocab_photo_sessions_<账号>`），**新收录词 + 勾选的已收录词作为整次拍照的完整词单整体成批学习**（不受每批 35 词限制——识别多少学多少）；已收录词（教材库已有或以前拍过的）标「已收录」、**不重复入库，默认勾选随本批学习，可取消勾选**（取消的不进本批；释义音标直接取账号词库快照，不耗查义额度；只勾选已收录词时无需查义可直接收录，2026-11-10）。考前拍整页教材词表 = 生成一个纯复习批。同一词进入多个批次时，同天到期只复习一次、结果同步计入各批；已学词数、宠物成长、家庭榜均**按词去重**统计。升级后队列中未学的旧拍照词自动包成一个历史会话继续优先学
- 切换账号后，**词库、学习进度、复习任务、学习记录、拍照生词队列同步切换**，互不干扰
- 账号定义在 `data/accounts.js`，可自行增删账号或改绑词库
- **词库页**（R09，2026-10-01；R09-2 全账号可删，2026-10-02；R23 分类筛选，2026-11-23）：从**学习进度页统计区任一格**（已学/复习中/已掌握三格带分类进入，词库总量进全部）或**首页工具格「词库」**进入当前账号的词库页，支持按**单词或释义搜索**、点单词中英连读、查看每个词的状态（待学习 / 第N批·复习中 / 第N批·已掌握）——可用来查某个词学没学、在第几批。顶部**分类 chips（全部/已学/复习中/已掌握，含各自计数）**可随时互切，计数与统计同源一致；搜索、点读与管理模式删除在筛选下照常可用（「全选结果」作用于当前分类+搜索结果）。**所有账号均可删除**：行右侧「删除」单删、右上「管理」勾选**批量删除**；**删除已进入学习的词会同时把它移出复习批次与错词本**（历史学习记录保留，统计随之更新），待学词删除后不再进入学习。教材词库删除为**软删除**（记录在本地存储，`data/*.js` 源文件不动，不可恢复）；从词库页删掉的内置词，拍照收词时可重新收录（不再标「已收录」）

### 拍照收词
- 首页蓝色「📷 拍照收词」卡片进入：**拍照 / 相册选图 → 自动识别印刷体英文单词 → 勾选 → 批量查询释义 → 收录**；入口页另有「**手动录入单词**」，不拍照直接收词（2026-11-10）
- **拍照/选图后可选编辑**（2026-11-08）：弹「直接识别 / 编辑后识别 / 按比例裁剪」三选一；编辑走微信官方编辑器（wx.editImage），裁剪按图片方向自适应比例（wx.cropImage，横图 4:3 / 竖图 3:4）。编辑/裁剪确认后用新图识别（后续 AI 纠错也基于新图）；取消则放弃本张；微信版本过旧或接口失败时自动用原图识别。编辑器真实能力以真机为准（需基础库 2.22.0/2.26.0+，鸿蒙支持）
- 识别双路线（R05-A，2026-10-01）：**主路线 = 智谱 GLM 视觉识别**（图片压缩后上传智谱云识别，准确率高、能还原 dialog(ue)→dialogue 这类拼写注记）；**断网或失败自动降级本机 VisionKit 识别**（图片不出设备）。GLM 内部带回退链（2026-11-21）：免费 `glm-4.6v-flash` 失败（如 429 限流）时按 `llm.config.js` 的 `fallbacks` 顺序自动切换收费 Key 重试（顺序靠前优先），全链失败才降级本机识别。已收录的词连同释义 / 音标存本地快照，之后不依赖网络。候选页底部标注本次识别实际使用的技术与照片去向：「AI 识别 · 智谱 GLM 视觉大模型 · 照片已上传云端」或「本机识别 · 微信 VisionKit · 照片未离开手机」（2026-11-08，文案经用户确认）
- 识别透明与纠错（R06，2026-10-01）：做过注记还原或低置信的词在候选页词下方灰色小字标注原图写法；**长按候选单词**或对待补义词点「**AI 纠错**」可带原图核对拼写，建议经确认后替换；`AUTO_FIX` 开关（默认关）开启后查义失败词自动拉取 AI 建议（仅展示，点「改用它」生效）
- 查义为有道词典接口（免插件、免认证），释义做 **K12 精简**（R07-A，2026-10-01）：每词性只保留首个常用义、最多 2 个词性、30 字内，滤除人名/语域标注等百科噪声（实测 176 字 → 29 字）；与**当前账号**有效词库（教材词 + 本账号收词）重复的词标「**已收录**」（另一教材的词允许收录）。已收录词**不重复入库、不经查义**（释义音标取词库快照），**默认勾选随本次收词会话整体进批学习，可取消勾选**——取消的不进本批；只勾选已收录词时无需查义，候选页直接出现收录按钮（2026-11-10，R15「拍了就学」默认行为保持）
- 识别候选列表每行右侧红色「**修改**」点按可修改单词拼写（预填当前词，仅限英文单词/短语），确认后更新候选并重算「已收录」状态（R08，2026-10-02 入口前移至识别列表）；**不支持手动修改中文释义**——释义只随英文单词联动更新，由「查询释义」统一获取。查义失败的词标「待补义」，可**重试**或**AI 纠错**；待补义词补齐释义前不进入收录
- **手动添加单词**（2026-10-27）：识别完成后，候选页和查义结果页列表底部均有「**＋ 添加单词**」，可补录漏识别或被粘连过滤的词。校验与查重同「修改」（仅英文单词/短语）；命中已收录词同样默认勾选随批学习（不查义），此前取消勾选的重新录入会自动补选；候选页添加的词随整批一起查义，结果页添加的词即时单独查义（同有道接口），查义失败同「待补义」（可重试 / AI 纠错，补齐前不收录）
- **手动录入单词**（2026-11-10）：拍照收词页入口「手动录入单词」＝不经过识别的收词路径——**逐个输入英文单词（校验与查重同上）→ 批量查询中文释义 → 收录**，加入当前账号的学习计划与词库。会话与词条带「手动」来源标：新单词页批次头「✏️ 手动录入批」、首页今日学习卡「（手动批）」、词库页「✏️手动」；学习、复习、删除与拍照词完全同管线。入口不依赖识别能力，鸿蒙端 / 未配置 AI 也可用；只录入已收录词时同样无需查义直接收录
- 收录后完成页一键「去学习」回到新单词页即**优先出批**（整次收词会话为一批，含勾选的已收录词，不受 35 词限制），进入 10 次间隔复习
- **启用 AI 主路线（一次性）**：
  1. 注册 [智谱开放平台](https://open.bigmodel.cn) → 控制台创建 **API Key**（建议低额度，便于泄露时撤换）
  2. 复制 `utils/llm.config.example.js` 为 `utils/llm.config.js`（同目录），填入 `apiKey`（模型名 / 接口域名同文件可调，以智谱文档为准）；可选填 `fallbacks` 回退链——免费模型限流（429）等失败时按数组顺序自动切换收费 Key（如 `glm-4.6v`）重试，顺序靠前优先（2026-11-21）。**该文件已被 `.gitignore` 排除、不会提交到仓库——本仓库为公开仓库，Key 严禁直接写进任何代码文件**。不创建该文件则始终走本机 VisionKit 识别，功能不受影响
  3. 代价说明（ADR-002 修订红线②的唯一豁免）：Key 随小程序包分发、可被反编译提取；照片会上传智谱云端识别
- **真机使用前的一次性配置**（开发者工具模拟器不受限）：
  1. mp 后台「用户隐私保护指引」声明「**摄像头**」与「**选中的照片或视频信息**」两项（2023-09 起强制，不配置真机拍照会被拦截），并在指引中补充照片用于 AI 识别、上传第三方的说明。新版后台入口：左下角账号头像 →「账号设置」→「服务内容声明」→「用户隐私保护指引」（旧版为「设置 → 服务内容声明」）；提交后需审核通过生效
  2. 「**request 合法域名**」加入 `https://dict.youdao.com`（downloadFile 已有，request 是独立列表需分别配置）；启用 AI 主路线时再加入 `https://open.bigmodel.cn`
  3. 微信基础库 ≥ 2.27.0（降级路线 VK 要求）；机型不支持时页面会提示
  4. 详细操作步骤：`docs/operations/platform.md`

### 新单词
- 每次出一批 **35 个**新单词，**按当前账号词库顺序**依次取词
- **本批增删单词**（2026-10-27）：新单词页每行右侧「**删除**」= 与词库页同义的账号级删除（待学词不再进入学习；已学词同步移出复习与错词本）；列表底部「**＋ 添加单词**」输入单词自动查义（有道）后**加入当前正在学的这批**——拍照批直接追加进该批，教材批存为「手动补充词」并在完成学习时随快照一起记入（不占 35 词游标进度）。查义失败不添加；添加词库已有词时按已有释义随本批再学；手动添加的入队词条带「手动」来源标（词库页显示「✏️手动」，2026-11-10 起）
- 列表上方有**播报模式切换**，默认「**手动点读**」：
  - **手动点读**：点任意单词的整行（英文 / 中文 / 空白处），只报读该词（先英文、再中文，释义自动分段），连读 3 遍、读完即停
  - **自动顺读**：点任意行后，本行连读 3 遍，播完自动接续之后的每个单词（同样英文 + 中文连读 3 遍），逐词向后直到最后一个词或点「停止学习」，当前词高亮并自动滚动到可视区域；右上角「开始学习」从第 1 个词起自动逐词连播，再点变「停止学习」随时暂停（已播完部分不记录进度，可随时从任意一行重新开始）
- 点击"完成学习，记入记录"后，记录本批的**学习日期 + 全部单词内容**，随后自动进入**学习模式**（见下）
- 词库用完会提示（可切换其他账号继续学）

### 学习模式（每批确认后）
每批单词**确认记入记录后**，可选择四种学习方式（学习记录页也可随时重学任意批次）：

| 方式 | 显示内容 | 点击后 |
|---|---|---|
| **展示英文** | 英文单词 | 翻出中文释义，并**报读英文 + 中文**（连读为 1 遍，间隔约 1.2 秒，共 3 遍） |
| **展示中文** | 中文释义 | 翻出英文单词，并**报读英文 + 中文**（同上节奏） |

- 两种模式点击后都统一报读"英文单词 + 中文释义（取首个义项，短词更易命中发音接口）"，**连读为 1 遍、每遍间隔约 1.2 秒、连续 3 遍**，方便专注跟读；再点一次会从头重报
- 支持"全部显示"和"重新开始"，并显示已点击进度（X/35）
- **每行右侧操作区**：🔊 快读一遍（英文 + 中文）；「**拓展**」弹出半屏面板，分栏展示该词的**衍生词（同根词）、近义词、3 条双语例句**（例句中目标词加粗，点右侧 🔊 逐句朗读）。数据来自有道词典接口：首次点击在线查询，之后**本地缓存**（离线也能看）；简单词可能没有衍生词段，面板自动隐藏，属正常现象
- **默写模式**（R13）：独立于上表两种浏览方式——看中文释义逐字母拼写英文（**出词自动读一遍中文释义**，点释义可重读；🔊 听音提示手动听英文，2026-11-22 起），错一个字母整词重打；错词回队列尾部，本轮内须再拼对；完成页统计首过正确率与打字速度。**拼错过的词随本轮结束记入错词本**（不重复记录，重拼对不撤回），复习连续答对 2 次自动移出
- **当日快测**（R16）：刚学完的整批马上自测一遍——显示英文、点开验证中文释义并报读，自评「记得 / 忘记」；忘记的词回到队尾**须再过一遍**。快测**不计入复习轮次**（2026-11-15 起），但标忘的词会**记入错词本**（不重复记录、重测答对不撤回），可反复做；两种浏览方式把整批全部翻开后，列表上方会浮现快测引导条

**关于朗读**：使用「有道词典」公开发音接口实现语音合成，**无需 API Key、无需插件、不受个人主体未认证限制**：
- 英文单词/短语：有道词典发音（`type=1` 英音，偏好美式可改 `utils/tts.js` 顶部 `EN_VOICE_TYPE = 2`），单词与常见短语发音稳定；发音人由有道按词条返回，不固定单一男女声
- 中文含义：有道词典词条发音（`https://dict.youdao.com/speech?le=zh&audio=…`），自动清理词性标注（n. / v. / int. 等）、剥离括号注释（复数、拼写提示），并**按「，；空格、。」等分隔符把释义拆成多段逐段连播**（多个义项、含用空格连接的都能各读出来）；仅对词典收录的词语有效，个别生僻词无声但不报错、不影响其他功能

真机使用前的唯一准备：配置**合法域名**（开发者工具模拟器不受限，可直接发声）：

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) →「开发」→「开发管理」→「开发设置」→「服务器域名」
2. 在「**downloadFile 合法域名**」中加入 `https://dict.youdao.com`
3. 重新编译后真机即可朗读英文并播放中文释义

### 复习
每一批新单词共安排 **10 次复习**，节点为学习日之后的：

> 第 1、2、3、5、7、9、12、14、17、21 天（R24，2026-11-23 起；此前为 1、2、3、4、6、8、11、13、16、21，中途批次的下一次到期按新间隔计算，已完成轮次不变）

- **前 3 次**（第 1、2、3 天）：复习该批**全部** 35 个单词，标记"忘记"的词进入该批的**遗忘池**；遗忘词连续答对两次才移出遗忘池，答错会重新累计
- **后 7 次**（第 5、7、9、12、14、17、21 天）：只复习**前几天复习中答错/忘记的单词**（遗忘池）；某轮答对则移出遗忘池，再错则保留到后续轮次
- 遗忘池为空时，该轮自动完成（说明这批掌握得好）
- **巩固循环**（2026-11-15 起）：10 次复习全部完成后**仍有遗忘词的批次不会断头**——距该批最近一次复习满 **7 天**自动再安排一轮巩固复习（只考遗忘池，规则同上：连续答对 2 次出池），池清空即彻底结业；总览页对这类批次显示「巩固 ▸」可随时手动提前
- **同一天多个批次到期时自动合并**为一次复习，重复单词去重
- 错过某天也没关系，逾期的任务会在下次打开时**补做**
- **两种复习视图（R17）**：复习页顶部「🃏 卡片 | 📋 列表」随时切换，选择按账号记忆（下次进入默认上次用的视图）——
  - **卡片**（逐词）：显示单词时**自动读一遍英文**（出词即读，不剧透中文）→ 点击“显示释义”（报读英文+中文）→ 自评“记得 / 忘记了” → 结束后显示统计并记录；点单词可随时重读（英文+中文）
  - **列表**（通览）：整批词单一次铺开，自控节奏——**点单词显示释义并朗读**（先回忆再看答案，不点不显示）；看过释义后行内出现 **🌱 拓展按钮**（打开与卡片同款的衍生词 / 近义词 / 例句弹层）；右侧圆圈标记忘记的词（不标 = 记得，可反复点切换），底部「完成复习」一次性提交
  - 两种视图可**中途互换**：判定与已看释义跨视图保留，后判覆盖先判（列表标忘、卡片又答"记得"则移出标记）；「当日快测」固定卡片（忘记回队尾机制依赖顺序出题）
- **拓展入口**：显示释义后卡片下方可点「🌱 拓展」查看该词衍生词 / 近义词 / 例句（与学习模式同款弹层，首次在线查询后本地缓存）
- **错词本联动**：判"忘记了"的词自动进入错词本；正式复习中连续两次判"记得"才会移出，复习结果页显示本次实际移出错词本的词数；错词本页面的「我会了」（需确认）和自由复习（答对即移出）仍可主动移出
- **复习优先引导**（R16 起；R24 起并入「今日学习」Hero 卡）：有到期任务时首页 Hero 显示「复习 X 词（N 批合并）· 新学 Y 词」并一键**先复习后学新**。到期批次均为"遗忘池已空的空轮"（无词可复习）时 Hero 只显示新学任务——进复习页会自动完成这些空轮（今日模式下自动衔接学新）
- **复习退出保护**（R19）：复习的结果是**一次性提交**（卡片答完最后一个词 / 列表点「完成复习」才记录），中途退出会丢失已标记的结果——因此复习进行中点返回（导航栏返回 / 安卓物理返回键）会弹出确认「还有 N 词未复习，退出将不保存」；「当日快测」不推进复习进度、退出不弹确认（标忘落池发生在做完之时，中途退出不登记）
- **没有到期任务的「今日看板」**：今天无到期批次时，复习页展示任务看板——连续学习天数、上次复习复盘（日期/批次/词数/错词数）、错词本待巩固词数、下一次到期批次与倒计时，让家人清楚"没有落后"
- **没有任务也能练**：看板提供两个动作——「复习错词本 N 词」（自由复习：答对自动移出错词本、忘记保留，**不计入**正式复习次数）与「提前复习第 N 批」（对未来即将到期的最近批次提前做一轮，完成后**计入**该批正式复习进度）

### 错词本
- 首页底部**工具格「错词本」**（R24 前为独立卡片），实时显示错词数量角标，点击进入；今日学习完成态的 Hero 卡也提供「自由复习错词本」直达
- 错词本 = 各批次**遗忘池的全局聚合**（同一词跨批次自动合并去重），展示单词、释义与来源批次
- 收录来源：正式复习判"忘记"、**当日快测标忘**、**默写拼错**（2026-11-15 起后两者也收录；登记不重复，重测答对不撤回）
- 移出途径（按验证强度）：
  1. 正式复习 / 巩固轮中**连续答对 2 次**（自动移出）
  2. 自由复习答对 1 次（主动自测，一次即信任；自动移出）
  3. 错词本列表点「我会了 ✓」（手动移出，弹确认防误触）
- 点错词可**快速朗读**（英文 + 中文连读一遍，回顾发音）

### 学习进度与统计（R24，2026-11-23）
- 首页**学习进度卡**：显示**当前并行几个批次**，每批一行摘要（`第 N 批 · 第 X 天 · 已复习 X/10 轮`进度条 + 状态点「今日第 N 轮 / 逾期 X 天 / 巩固中」+ 毕业日），最多展示 3 行；「第 X 天」= 今天是学习日起第几天（学习当天 = 第 1 天）。**并行批次含巩固中的批**（十轮完成但错词池未清空）
- 点击进入**学习进度页**（`pages/progress`）：
  - 顶部**四格统计**（自首页迁移）：「已学单词」「词库总量」「复习中」「已掌握」——已学表示进入过学习记录，复习中表示尚未完成该词所属批次的 10 轮正式复习（= 已学 − 已掌握），已掌握表示完成 10 轮且当前不在任何批次遗忘池中。**四格均可点击**，打开词库页对应分类的单词清单（页内顶部 chips 可在 全部/已学/复习中/已掌握 间互切，搜索与管理模式删除在筛选下照常可用）；每格下有小注说明口径，底部有一行随学习阶段变化的鼓励文案
  - **在学批次十轮时间线**：每批一张卡（学习日 · 今天第 X 天 · X/10 轮进度条 · 下一轮日期与词数（逾期标红）· 毕业日 = 学习日 + 21 天），下方逐轮展示——已完成轮显示 ✅ **实际完成日期**，未完成显示 ⬜ **计划日期**（学习日 + 间隔），节点已过未做标红「逾期」，当天节点标「今日」，第 10 轮带 🎓 毕业标；巩固中的批时间线尾部追加历次巩固轮（按实际日期）
  - **已毕业批次**默认折叠成一组（点「展开 ▾」查看各批毕业日期）

### 教材总览
- 首页工具格**「教材总览」**进入（R24 前为教材进度卡片 + 查看链接）；全书学了多少、还剩多少在总览页一眼可见
- 点击进入**教材总览**页：把当前词库按每批 `BATCH_SIZE`（35 词）自动**划分成若干「章」**，逐章显示【状态徽标】复习进度 X/10、遗忘词数（联动错词本）、最近学习时间（🕒 今天 / 昨天 / N 天前，超过 7 天显示日期；取该批最后一次复习日期，无复习记录用学习日，未学批不显示）
- 点任意一章可**展开看该批全部单词（含释义）与每次复习记录**；未学/当前批点「去学习」直接进入新单词页，已学批点「重学」直接进入学习模式
- **可直接复习任意已学批**：正处在复习过程中的批次（复习中状态）右侧有「复习 ▸」，点它会直接进入该批本轮复习（前 3 轮复习全批单词、第 4 轮起复习遗忘池），完成计入该批复习次数并联动错词本；已完成 10 轮但仍有遗忘词的批次右侧有「巩固 ▸」（提前做下一轮巩固）；未轮到的新批会提示按顺序学习
- 切换账号后总览随账号同步切换（词库、进度各自独立）

### 学习记录
首页工具格**「学习记录」**（R24 前为统计卡底部链接）可翻看：每批的学习日期、全部单词内容、10 次复习的完成情况、每次复习的对错统计、当前遗忘池剩余词数。每批带有"两种方式学习"按钮，可随时进入学习模式重学。

## 四、替换或扩充词库

编辑 `data/junior.js` / `data/primary.js`，保持格式即可（`w`=单词或短语，`m`=释义；`p`=音标为可选项，现有词库未包含音标）：

```js
module.exports = [
  { w: 'abandon', m: 'v. 放弃；抛弃' },
  { w: 'be good at', m: '擅长……' },
  ...
];
```

已学过的记录保存了单词快照，替换词库不影响历史记录；新批次从上次的进度位置继续按顺序取词。

新增账号或改绑词库：编辑 `data/accounts.js`：

```js
module.exports = {
  list: [
    { id: 'junior', name: '初中人教版', desc: '初中人教版单词短语 + 高频考点', bank: require('./junior.js') },
    { id: 'primary', name: '小学人教版', desc: '小学人教版单词短语 + 高频考点', bank: require('./primary.js') }
  ]
};
```

拍照生词不占 `accounts.js`（R14）：词存各账号队列 `vocab_photo_words_<账号>`，由拍照收词自动维护，`accounts.js` 只配置初中 / 小学两个教材账号。
