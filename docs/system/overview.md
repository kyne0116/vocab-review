# 系统总览

启航成长记是一个本地优先的家庭单词学习小程序：选择预置账号，学习教材词或拍照词，保存批次快照，按 1/2/3/4/6/8/11/13/16/21 天复习，并把答错词聚合到错词本。

## 当前闭环

账号 → 词库 → 拍照收词（可选）→ 新词批次 → 学习模式 → 正式复习 → 遗忘池/错词本 → 统计反馈。

## 边界

所有学习数据保存在当前设备；没有登录、云同步、自建服务器或微信认证服务端能力。智谱 GLM 是拍照识别主路线，VisionKit 是失败降级；有道提供查词、拓展和 TTS。

## 主要模块

页面负责交互；`utils/store.js` 负责账号、批次、复习和持久化；`utils/llm.js`、`ocr.js`、`wordParser.js` 负责识别；`lookup.js`、`tts.js` 负责词典和朗读。
