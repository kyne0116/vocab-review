## 产品定位

- 给家人长期使用的单词记忆微信小程序，个人主体「启航成长记」（appid `wx883c54d2308a2450`），未通过微信认证、不计划认证
- 核心方法：间隔重复（Leitner / Anki 思路）—— 每批 35 词，学习后第 1、2、3、4、6、8、11、13、16、21 天共 10 次复习；前 3 轮复习全批，后 7 轮只复习遗忘池
- 多账号 = 多词库，进度完全独立：初中人教版（343 条）、小学人教版（229 条）
- 发布路径：体验版给家人长期使用（个人主体无需认证；正式发布可选）
- 架构红线：免插件、免 API Key、免服务器、不依赖微信认证能力（详见根 `AGENTS.md`）

## 当前需求：拍照收词

用户原话：

> 拍照识别英文单词，然后自动识别和解析，并对应的生成中文翻译，连同英文+中文一起收录至单词本中

前置约束：小程序未通过微信认证（个人主体），方案必须在架构红线内。

### 目标拆解

1. 拍照或从相册选取印刷体英文材料（课本、练习册、绘本；相册入口同时覆盖电子教材截图）
2. OCR 识别图中的英文文本
3. 解析提取候选单词（去噪、去重、过滤）
4. 批量生成中文释义（词典级优先，含音标）
5. 用户确认后，与内置词库同构入库（`{ w, m, p }`）
6. 收录的词自动进入现有间隔重复流水线（批次 / 复习 / 遗忘池 / 错词本 / TTS 全部复用，零新增学习成本）

### 非目标（v1 明确不做）

- 手写体识别：OCR 面向印刷体，产品上引导拍摄印刷材料
- 自动从句子中切分短语词条：相邻词自动组词不可靠，v1 只提取单个单词
- 云端同步 / 多端共享：纯本地存储架构不变
- 以付费 OCR / 翻译服务为主路线
