# 拍照收词技术选型与验证

更新时间：2026-09-06。本文记录选型对比与验证证据；正式决策记录见 `adr/ADR-001-拍照收词采用VisionKit端上OCR与有道词典查词.md`。

## 结论

推荐组合：**VisionKit 端上 OCR（静态图模式）+ 有道词典 jsonapi 查词 + 「拍照生词本」动态账号**。全程免认证、免插件、免 API Key、免服务器，与项目架构红线完全一致。

## 查词候选对比

| 方案 | 质量 | 费用 | 依赖 | 评价 |
|---|---|---|---|---|
| **有道 jsonapi**（推荐） | **词典级**：音标 + 分词性义项 | 免费 | 域名加入 request 白名单（与 TTS 同域名，已有 ICP） | 延续 TTS 同源思路；非官方接口是唯一顾虑（F8） |
| 百度翻译 API | 机翻级 | 有免费额度（需 Key） | Key 嵌入 + 新域名 | 无音标、义项质量不如词典；违反免 Key 红线 |
| 内置离线词典（ECDICT 子集） | 取决于裁剪 | 免费 | 包体积 + 数百 KB~MB | 留作日后零网络依赖的兜底，当前不引入 |

## 有道 jsonapi 实测样本（2026-09-06）

```
q=spring → usphone: sprɪŋ
           trs: ["n. 春天，春季；泉，泉水；弹簧…", "adj. 春天的", "v. 跳，跃；突然弹开…"]
q=go over → 音标 + "v. 仔细检查；复习，重温…"（短语有词典词条）
q=be good at → "擅长于：具有某种技能或才能…"（短语有词典词条）
```

释义格式与现有词库 `m` 字段同构（`v. 放弃；抛弃`），并可顺带启用 `p` 音标字段。
