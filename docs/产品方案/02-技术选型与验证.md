# 拍照收词技术选型与验证

更新时间：2026-10-01。本文记录选型对比与验证证据；正式决策记录见 `adr/ADR-001-拍照收词采用VisionKit端上OCR与有道词典查词.md` 与 `adr/ADR-002-拍照收词引入智谱GLM视觉识别为主路线并修订免Key红线.md`。

## 结论

现行组合（R05-A，2026-10-01 拍板）：**智谱 GLM 视觉识别（主路线，免插件/免服务器/免认证，Key 嵌入为红线②唯一修订项）+ VisionKit 端上 OCR（自动降级路线）+ 有道词典 jsonapi 查词 + 「拍照生词本」动态账号**。原始组合（VisionKit 单路线）见 ADR-001 与本文历史版本。

## 有道 jsonapi 实测样本（2026-09-06）

```
q=spring → usphone: sprɪŋ
           trs: ["n. 春天，春季；泉，泉水；弹簧…", "adj. 春天的", "v. 跳，跃；突然弹开…"]
q=go over → 音标 + "v. 仔细检查；复习，重温…"（短语有词典词条）
q=be good at → "擅长于：具有某种技能或才能…"（短语有词典词条）
```

释义格式与现有词库 `m` 字段同构（`v. 放弃；抛弃`），并可顺带启用 `p` 音标字段。
