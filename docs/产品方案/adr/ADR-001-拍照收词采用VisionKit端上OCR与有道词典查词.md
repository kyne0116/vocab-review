# ADR-001：拍照收词采用 VisionKit 端上 OCR 与有道词典 jsonapi 查词

- 状态：**Accepted**（2026-09-06 R01–R04 拍板确认，R02=A）
- 提出日期：2026-09-06

## 背景

用户需要「拍照识别英文单词 → 自动解析 → 生成中文翻译 → 英中一起收录单词本」。本项目为个人主体未认证小程序，架构红线：免插件、免 API Key、免服务器、不依赖微信认证能力。OCR 与查词是仅有的两个必须借助外部能力的环节，需在红线内选型。候选与验证证据见 `../02-技术选型与验证.md`。

## 决定

1. OCR 主路线采用微信 VisionKit：`wx.createVKSession({ track: { OCR: { mode: 2 } } })` 静态图片检测，基础库 2.27.0+（项目 libVersion 2.32.3 满足），识别结果经 `VKOCRAnchor.text` 获取。
2. 查词主路线采用有道词典公开接口 `https://dict.youdao.com/jsonapi?q=`，与现有 TTS 同域名；释义取 `ec.word[0].trs`（分词性义项），音标取 `usphone`，入库格式与内置词库同构。
3. OCR 与查词各做 provider 抽象（`recognize(imagePath) → [text]`、`lookup(word) → {w, m, p}`），实现可替换，上层流水线不感知。
4. 备选路径：百度智能云 OCR 通用标准版（个人认证 1000 次/月免费，需嵌 Key），仅在 VisionKit 不可用时作为降级 provider 启用。
5. 已收录词连同释义 / 音标以快照存本地（`vocab_photo_bank`），之后不依赖任何网络接口。

## 理由

- VisionKit：官方、免费、端上识别（图片不出设备）、无认证要求，四条红线全部满足。
- 有道 jsonapi：2026-09-06 实测存活，返回词典级词条（音标 + 分词性义项），质量为候选中最高；域名已有 ICP 且已配置于 downloadFile 白名单，request 白名单补配即可。
- 两者均无需在代码中嵌入任何凭据，包体可被反编译也不泄露秘密。

## 未采用方案

- **微信同声传译插件**（翻译 / 语音）：个人主体小程序不可添加第三方插件（F1，已验证排除）。
- **微信官方 OCR** `/cv/ocr/comm`：服务端接口，需 access_token + 服务市场开通，与免服务器红线冲突（F2）。
- **百度翻译 / 腾讯云 TMT 为主路线**：需 API Key 嵌入小程序代码，违反免 Key 红线；机翻质量无音标、无分词性义项。
- **内置离线词典（ECDICT 子集）为主路线**：数百 KB 包体积代价换取的离线能力当前无需求；保留为 jsonapi 失效时的兜底选项。

## 影响

- 「request 合法域名」需新增 `https://dict.youdao.com`（downloadFile 已有，两列表独立配置）。
- mp 后台需配置用户隐私保护指引（「摄像头」「选中的照片或视频信息」）。
- 最低基础库版本需 ≥ 2.27.0，或代码内 `wx.isVKSupport` 检测并优雅降级。
- VKSession 在开发者工具模拟器大概率不可用，OCR 链路开发与验证必须走真机（预览 / 真机调试）。

## 验证与退出条件

- **真机预验证**：在家人主力机型上用课本 / 练习册照片实测 VK OCR 印刷体识别率，记录 `wx.isVKSupport` 覆盖情况（F6）。
- **退出条件**：若主力机型 VK OCR 不可用或识别率不可接受 → 切换百度 OCR provider（上层流水线不变）；若有道 jsonapi 失效或大规模限流（F8）→ 启用百度翻译 provider 或内置离线词典兜底，存量快照词不受影响。
- **验收口径**：拍照 → 收录 → 进入拍照生词本批次 → 复习 / 错词本 / TTS 全链路可用（L4）。
