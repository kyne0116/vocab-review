# ADR-002：拍照收词引入智谱 GLM 视觉识别为主路线，并修订「免 API Key」红线

- 状态：**Accepted**（2026-10-01 R05-A 用户拍板确认）
- 提出日期：2026-10-01

## 背景

拍照收词的 VisionKit 端上 OCR 链路经三轮真机迭代（小图放大 → 按列分块 → 粘连串还原）已达到**设计上限**：`english.jpg`（963×246 压缩词表图）候选从 1 词恢复到 25 词（真词 12+），与 Node 模拟基线逐词一致。剩余错误分三类，**原理上无法靠本地算法/词典修复**：

1. 多词残块（mannerhono / provecough / elderdirect / packawakebottom）——待收藏生词不在内置词库，无切分依据；
2. 字母误读（atack / dassic）——词典只匹配正确拼写；
3. 括号注记拆词（hono(u)r 的 r 被物理分到相邻 token）——任何本地算法拼不回。

同日可行性验证（事实）：大视觉模型（智谱 GLM 系列）直读同一张压缩图，可高置信读出绝大部分词并纠正上述全部三类错误（classic / attack / honor），天然免疫粘连与括号问题；仅个别 ~8px 小字不确定，原图（3000px 级相机直拍）接近全对。

## 决定

1. **主路线**：拍照收词识别采用智谱 GLM 视觉模型（`utils/llm.js`）：压缩长边 ≤1600 → base64 → `wx.request` 直连开放平台 → 提示词约束只输出 JSON 单词数组（教材拼写注记还原完整拼写，如 dialog(ue)→dialogue）。provider 接口 `recognize(imagePath) → [text]` 与 VisionKit 同构（延续 ADR-001 的 provider 抽象）。
2. **红线②修订（仅此一处）**：允许在 `utils/llm.js` 嵌入智谱 API Key，条件 = 低额度、可撤换的专用 Key，用户显式接受小程序包被反编译提取的风险；泄露处置 = 控制台删除重建 + 改代码重新上传。其他功能不得新增嵌入密钥。
3. **自动降级**：未配置 Key / 断网 / 接口失败 / 超时（20s）/ 载荷过大 → 自动降级 VisionKit 本地识别（放大 + 分块 + 粘连还原链路保持不变），两条路线产出统一走 wordParser 解析与查义/收录流水线。
4. **鸿蒙端恢复可用**：LLM 仅需网络不依赖 VisionKit，华为鸿蒙机（原入口降级提示）在配置 Key 后可用拍照收词。

## 理由

- 准确率代差：视觉大模型一次调用直接返回干净单词列表（预期 ~30/30，VK 链路 12+），并顺带解决粘连、误读、括号拆词三类本地不可解错误。
- 工程条件：纯 `wx.request` 直连，免插件、免服务器、不依赖微信认证，四红线仅②冲突且经拍板修订；家庭用量（每天数张）在免费/最低额度内。
- 降级安全网：VK 链路完整保留，LLM 任何失败不阻塞功能；`API_KEY` 置空即回到 VK-only 行为。

## 未采用方案

- **R05-B（不动红线，仅备选 + 常用词词典）**：词典无法修复字母误读与括号拆词，天花板明显低于 A。
- **R05-C（LLM 仅做文本后处理）**：照片不出设备（隐私最优、费用近零），但受 VK 字母错误上限约束（sily 类无解），且仍需同样修订红线②。
- **云函数藏 Key**：引入后端与月费，违反红线③，复杂度不值。

## 影响

- mp 后台「request 合法域名」需新增 `https://open.bigmodel.cn`（域名以智谱官方文档为准，真机域名校验依赖白名单）。
- 「用户隐私保护指引」需补充：照片用于 AI 识别、上传第三方（智谱）的说明；拍照页对用户透明展示「已启用 AI 深度识别」提示。
- 小程序包内含 API Key（接受提取风险）。**仓库为公开仓库（2026-10-01 GitHub API 实测）：Key 隔离存放于 `utils/llm.config.js`（gitignore 排除、不入库；模板 `llm.config.example.js`），严禁写入任何入库文件。**
- LLM 路线在开发者工具模拟器可测（仅依赖 wx.request），VK 降级链路仍须真机。
- 待验证（F9）：智谱当前视觉模型名（默认 `glm-4v-flash`）、免费额度、接口域名，以开放平台控制台为准。

## 验证与退出条件

- **验证**：真机相册选 `english.jpg` → 候选预期 ~30 词（含 dialogue/honor/classic/attack 等此前错误项）；断网重试应自动降级 VK 得到 25 词基线；查义 → 收录 → 学习全链路正常。
- **退出条件**：智谱接口长期不可用 / 费用异常 / 识别质量劣化 → `API_KEY` 置空回 VK-only（代码无需回滚）；或按 ADR-001 备选切换百度 OCR。
