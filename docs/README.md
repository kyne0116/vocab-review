# 文档系统

本目录按 Agent 工作流组织。系统蓝图描述当前代码事实；业务域文档描述修改契约；决策文档记录难以逆转的取舍；历史文档只保存已完成证据。根目录 [README.md](../README.md) 是家人使用、运行和发布说明。

## 入口

| 任务 | 入口 |
|---|---|
| 任何开发任务 | [Agent 起点](agent/00-start-here.md) |
| 快速理解全局 | [系统总览](system/overview.md) |
| 查找数据和模块边界 | [运行时地图](system/runtime-map.md)、[存储契约](system/storage-contract.md) |
| 修改某个功能 | [业务域契约](domains/) |
| 发布或真机验证 | [运维手册](operations/) |
| 了解为什么这样设计 | [决策记录](decisions/) |

## 写作规则

1. 当前代码、配置和测试是行为真相；文档必须给出代码落点和验证等级。
2. 规划、待验证和历史不得写进当前实现契约。
3. 一个事实只有一个正本；其他文档只链接，不复制。
4. 修改行为、数据约定或架构时，同轮更新对应契约和验证记录。
5. 新文档必须能回答：触发条件、修改入口、数据影响、完成标准、验证命令。
