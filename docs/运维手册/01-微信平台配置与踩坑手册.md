## 3. 操作实录

### 3.1 用户隐私保护指引（拍照收词前置，2023-09 起强制）

适用：真机调用 `wx.chooseMedia`（拍照 / 相册）被拦截时。需声明两项：**摄像头**、**选中的照片或视频信息**。

1. 路径见第 2 节，点「去完善」
2. **声明选择页（关键）**：默认选中第一项「未以任何方式处理用户的任何信息」——**不要直接点确定**（确认该项等于完结，不会出现任何后续表单）。改选第二项「**本小程序处理了用户信息，将如实填写并及时更新用户信息处理情况**」，再点「确定以上内容」
3. 信息填写页（2026-09-06 实测走通）：「增加信息」添加两条，各填场景说明：
   - **摄像头**：`拍照识别印刷体英文单词，用于单词收录学习`
   - **选中的照片或视频信息**：`从相册选择照片识别英文单词，用于单词收录学习`
   - 其他信息类型不加
4. 提交 → 状态转「审核中」→ **微信审核通过后生效**（几分钟到数小时，期间真机仍被拦截）

### 3.2 服务器域名（request 查词 / downloadFile 朗读）

1. 开发设置页内下滚到「服务器域名」→「修改」
2. 流程两步：① 身份验证（管理员扫码）→ ② 配置服务器域名
3. 七个输入框的协议头要求（页面提示实录）：

| 列表 | 协议头 | 本项目 |
|---|---|---|
| request 合法域名 | `https://` | `https://dict.youdao.com`（拍照查词） |
| socket 合法域名 | `wss://` | 留空 |
| uploadFile 合法域名 | `https://` | 留空 |
| downloadFile 合法域名 | `https://` | `https://dict.youdao.com`（朗读，已配） |
| udp / tcp 合法域名 | `udp://` / `tcp://` | 留空 |
| DNS 预解析域名 | 无需协议头，最多 5 个 | 留空 |

4. 域名间用 `;` 分隔；**每月有修改次数上限**（官方 50 次/月，页面会显示剩余次数），改前核对拼写一次改对

### 3.3 体验版发布与成员（家人长期使用）

完整发布步骤见根 `README.md`「二、编译与发布体验版」。运维视角注意项：

- 流程：工具「上传」→ 后台「管理 → 版本管理」选为体验版 → 「管理 → 成员管理 → 体验成员」添加（个人主体 ≤ 15 人）
- 版本号递增便于区分；家人下次进入小程序自动更新
- 「预览」临时二维码约 2 小时过期，长期使用不走预览码

## 5. 开发者工具与真机注意项

- **模拟器 ≠ 真机**：`urlCheck=false` 且模拟器不校验合法域名 → 一切域名问题只在真机暴露；VK OCR（VKSession）模拟器不可用（已实证，探测结果随调试基础库渠道漂移且不可信，见踩坑 #8）
- **基础库**：VK OCR 要求 ≥ 2.27.0，项目 `libVersion` 2.32.3 满足；机型不支持时拍照页有 `wx.isVKSupport` 检测与提示
- **真机 VK 诊断（原「F6 真机验证流程」，vktest 页 2026-09-06 已移除）**：验证页完成 F6/F7 使命后随收尾移除，代码在 git 历史提交 `695bf84` 中，需要现场诊断时可临时找回；日常真机 VK 排查 = 拍照页错误弹窗（errno 带码表翻译）+「真机调试」控制台
- **真机错误不落本机日志**：预览 / 体验版在手机上的运行错误（含 VKSession errno）不会写入开发者工具日志（实测 2026-09-06：本机四份日志均无 2003000 记录），排查靠页面错误文案（errno 带码表翻译）或「真机调试」控制台（vktest 复制通道已随页面移除）
- **白屏处理**：工具栏「清缓存 → 清除全部缓存」后重新编译
- **上传权限**：开发者工具登录的微信须为该 AppID 的管理员，或后台「成员管理」中的项目成员
