# 拍照收词域

## 契约

图片进入 GLM 识别；失败时进入 VisionKit OCR。拍照/选图后先弹三选一菜单（直接识别 / 编辑后识别 / 按比例裁剪）：编辑用 wx.editImage、裁剪用 wx.cropImage（官方媒体能力，比例按图片方向自适应 4:3/3:4），确认后用新图进入识别，取消则放弃本张，接口不可用或失败时回退原图直接识别。候选页底部标注实际产出结果的识别路线（llm = 智谱 GLM 云端 / vk = 微信 VisionKit 本机）及照片去向，文案固定不随模型版本变化。文本经过候选提取、去重和噪声过滤，用户确认后批量查义。识别完成后可在候选页或查义结果页手动添加单词：仅接受英文单词/短语并按候选查重，已收录词置灰随批学习不经查义；候选页添加随批量查义，结果页添加即时单独查义（同有道接口），与拍照词走同一收录管线。查义失败的词不能收录。已存在词显示为已收录，可随照片会话学习；照片会话保持顺序并作为整体批次优先。

## 代码落点

`pages/photo`、`utils/llm.js`、`utils/ocr.js`、`utils/wordParser.js`、`utils/lookup.js`、`utils/store.js` 的照片会话函数。

## 完成标准

候选、查义、收录、失败降级和账号隔离均有 L0/L1 证据；手动添加单词为页面级交互，各分支由 L2 模拟器验证；摄像头、隐私弹窗、真实网络和设备 OCR 只能由 L3/L4 证明。编辑/裁剪三选一菜单与识别路线标注为页面级交互：菜单与降级回退走 L2，wx.editImage / wx.cropImage 的真实编辑器行为只能由 L3 真机证明（2026-11-08 实现时模拟器未验证）。
