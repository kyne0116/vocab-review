# 正式复习域

每批次在学习日后的第 1、2、3、4、6、8、11、13、16、21 天安排十轮。前 3 轮复习全量，之后只复习遗忘池；正式复习中遗忘词连续两次答对才移出遗忘池，答错会重置连续答对次数。正式复习一次性提交；中途退出不保存部分结果。

代码落点：`utils/store.js` 的 `OFFSETS`、`buildReviewSession`、`finishReview`、统计函数；页面 `pages/review`、`pages/spell`。正式复习中，遗忘词必须连续两次答对才移出遗忘池；答错会重置连续答对次数。统计区分已学、复习中和已掌握（完成10轮且不在遗忘池）。验收：到期、逾期合并、逐词忘记、错词联动和自由复习隔离通过 L1。
