# 系统测试与等级缺陷闭环

## Trigger
用户要求按项目文档对当前小程序进行系统测试，并持续修复已发现缺陷。

## Workflow
1. 读取 AGENTS.md、README.md、docs/system、docs/domains 与测试入口，建立功能验收矩阵。
2. 主代理运行 L0/L1 测试和文档对照；专门子代理独立审查等级/成长相关功能并报告缺陷证据。
3. 对每个缺陷记录复现步骤、期望行为、实际行为、影响等级和验证命令。
4. 主代理向修复子代理派发具体缺陷；修复后运行对应测试与全量回归。
5. 仅当所有已测试等级功能无缺陷且验证证据齐全时结束；更新 app.js 最后一实现时间戳。

## Checkpoint
主代理在每轮修复后审阅测试结果和文档一致性；发现冲突时暂停并请求裁决。

## Brief
输出修改文件、缺陷修复、测试命令及通过结果，明确真实场景和仍待 L2/L3 验证项。
